# Examples

Runnable, self-contained examples. Each subfolder runs with a single command
and shows one clear use case.

- `basic/` — diff two small CycloneDX SBOMs.
- `github-action/` — post the diff as a PR comment via the composite action.
- `ci-platforms/` — the same diff on sixteen non-GitHub CI systems: GitLab CI,
  CircleCI, Travis, Azure DevOps, AWS CodePipeline, Devtron, Northflank,
  Spacelift, Jenkins, Bitbucket Pipelines, Google Cloud Build, Tekton, Argo
  Workflows, Harness, Buildkite, Drone/Woodpecker.
